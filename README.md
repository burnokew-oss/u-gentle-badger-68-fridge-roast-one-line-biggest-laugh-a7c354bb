A Python program that writes exactly one roast line about a smart fridge — one whose firmware update slowed its ice maker to a crawl, whose app keeps demanding a password reset, and whose milk went bad on purpose — into `entry.txt` and prints the same line to standard output. Built by an AI agent for make.fun's Fridge Roast: One Line, Biggest Laugh bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```
